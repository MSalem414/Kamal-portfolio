# Kamal El Sayed Kamal - Professional Portfolio

A clean English-only portfolio website for Kamal El Sayed Kamal, written in first person and designed for recruiters, clients, and technical teams.

## How to run

1. Extract the ZIP file.
2. Open `index.html` in your browser.
3. Upload the folder to Netlify, Vercel, GitHub Pages, or any static hosting service.

## Design updates

- Professional web typography using Inter, Plus Jakarta Sans, and IBM Plex Mono fallbacks.
- Calm navy/blue visual palette with softer highlights and reduced glow.
- Bottom-right floating contact icons with 3D hover/mouse-near interaction.
- WhatsApp and email colors match their familiar app styles.
- Fully responsive layout for desktop, tablet, and mobile.

## Included files

- `index.html` - website structure and English content
- `styles.css` - responsive professional design, typography, calm colors, 3D effects, floating contact icons
- `script.js` - navigation, project filtering, contact form, scroll reveal, icon motion effects
- `Kamal-El-Sayed-CV.pdf` - downloadable CV
